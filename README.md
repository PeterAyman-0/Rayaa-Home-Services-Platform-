# 🏠 رعاية - نظام سوق محلي لخدمات المنازل

<div dir="rtl">

## 📝 نبذة عن المشروع

**رعاية** هو نظام ويب متكامل لإدارة خدمات المنازل المحلية (نظافة وصيانة). المشروع مصمم لتسهيل عملية طلب وإدارة خدمات المنازل بشكل احترافي وفعال.

### ✨ المميزات الرئيسية

- 🎨 **واجهة مستخدم جذابة** - تصميم عصري واحترافي بدعم كامل للغة العربية
- 🔧 **إدارة الخدمات** - عرض وإدارة خدمات النظافة والصيانة
- 📋 **نظام الطلبات** - إنشاء وتتبع طلبات الخدمات
- 🗄️ **قاعدة بيانات قوية** - MongoDB مع Mongoose للتعامل مع البيانات
- 🔐 **أمان البيانات** - استخدام Environment Variables لحماية البيانات الحساسة
- 📱 **تصميم متجاوب** - يعمل على جميع الأجهزة

---

## 🛠️ التقنيات المستخدمة

### Backend (الواجهة الخلفية)

- **Node.js** - بيئة تشغيل JavaScript
- **Express.js** - إطار عمل الويب
- **MongoDB** - قاعدة البيانات
- **Mongoose** - ODM للتعامل مع MongoDB

### Frontend (الواجهة الأمامية)

- **HTML5** - هيكل الصفحات
- **CSS3** - التنسيق والتصميم
- **JavaScript** - البرمجة التفاعلية (قيد التطوير)

### أدوات إضافية

- **dotenv** - إدارة المتغيرات البيئية
- **CORS** - إدارة الطلبات من نطاقات مختلفة
- **Nodemon** - إعادة التشغيل التلقائي أثناء التطوير

---

## 🚀 البدء السريع

### المتطلبات الأساسية

- Node.js 16.0.0 أو أحدث
- MongoDB (محلي أو Atlas)

### التثبيت

1. **استنساخ المشروع أو تحميله**
2. **تثبيت المكتبات:**
   ```bash
   npm install
   ```
3. **إعداد ملف البيئة (.env):**
   - الملف موجود بالفعل للحفاظ على البيانات الحالية
   - أو انسخ `.env.example` إلى `.env` وعدّل القيم

4. **تشغيل المشروع:**

   ```bash
   # التشغيل العادي
   npm start

   # وضع التطوير (مع إعادة التشغيل التلقائي)
   npm run dev
   ```

5. **إضافة بيانات تجريبية (اختياري):**

   ```bash
   npm run setup
   ```

6. **افتح المتصفح:**
   ```
   http://localhost:5000
   ```

## 🔌 API Endpoints

### الخدمات (Services)

```http
GET /api/services
```

- **الوصف:** جلب جميع الخدمات المتاحة
- **الاستجابة:**
  ```json
  {
    "success": true,
    "count": 10,
    "data": [...]
  }
  ```

### الطلبات (Orders)

```http
GET /api/orders
```

- **الوصف:** جلب جميع الطلبات
- **الاستجابة:**
  ```json
  {
    "success": true,
    "count": 3,
    "data": [...]
  }
  ```

```http
POST /api/orders
```

- **الوصف:** إنشاء طلب جديد
- **Body:**
  ```json
  {
    "user_name": "محمد أحمد",
    "user_phone": "01012345678",
    "user_address": "القاهرة، مدينة نصر",
    "serviceId": ["SERVICE_ID"]
  }
  ```
- **الاستجابة:**
  ```json
  {
    "success": true,
    "message": "تم استلام الطلب بنجاح!",
    "data": {...}
  }
  ```

## 📊 نماذج البيانات (Models)

### Service Model (الخدمات)

```javascript
{
  name: String,           // اسم الخدمة (مطلوب)
  description: String,    // وصف الخدمة (مطلوب)
  price: Number,          // السعر (مطلوب)
  department_id: ObjectId // معرف القسم
}
```

### Order Model (الطلبات)

```javascript
{
  user_name: String,        // اسم المستخدم (مطلوب)
  user_phone: String,       // رقم الهاتف (مطلوب)
  user_address: String,     // العنوان (مطلوب)
  serviceId: [ObjectId],    // قائمة الخدمات (مطلوب)
  order_date: Date,         // تاريخ الطلب
  status: String            // حالة الطلب (جديد، قيد التنفيذ، مكتمل، ملغي)
}
```
